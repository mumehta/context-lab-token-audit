# Context Lab design

A user sits at a daylight desk after hitting a usage limit, comparing evidence while planning the next task. Bright neutral surfaces keep dense findings legible; deep green anchors navigation and selected controls.

Restrained palette with a persistent forest-green navigation rail. System sans for controls, monospace for formulas and commands. Split audit workspace, ruled diagnostic rows, generous margins, and an explicit evidence drawer for each finding. Body 16px, metadata 14px, corners 8px. Color is paired with severity text. No decorative images.
